GitHub sign-in

Complete both sections inside your lab VM. Use your assigned lab Azure account, not a personal account.

Your sign-in details are in Resources > Azure Portal.

Browser sign-in

  1. Open Microsoft Edge inside the VM.
  2. Enter this address in the browser's address bar: https://github.com/enterprises/skillable-events/sso
  3. Select Continue.
  4. Sign in with the Username and Temporary Access Pass (TAP) or Password shown in the Azure Portal card. If Microsoft shows a different account, select Use another account.

Leave this browser open for the next section.

Use single sign-on (SSO). Do not enter the lab credentials into the standard github.com username/password form. That form reports "Incorrect username or password" for this lab account.

GitHub CLI sign-in

For each terminal prompt, use the arrow keys to select the answer, then press Enter.

  1. Open Windows Terminal (PowerShell) inside the VM and run: gh auth login

    If asked whether to re-authenticate an existing sign-in, select No and go to step 8 to check the account.

  2. At Where do you use GitHub?, select GitHub.com.
  3. At the preferred protocol prompt, select HTTPS.
  4. At Authenticate Git with your GitHub credentials?, select Yes.
  5. At How would you like to authenticate GitHub CLI?, select Login with a web browser.
  6. Note the one-time code shown in the terminal, then press Enter to open the browser.
  7. Enter that code in the browser and select Continue, then Authorize github. If asked to sign in again, use the same lab account and the SSO address above. When the page says your device is connected, return to the terminal.
  8. Run: gh auth status

    Before continuing: confirm it says Logged in to github.com with your assigned lab account, not a personal account.

If it still says you are not signed in, run gh auth login again and repeat the CLI steps. Ask the facilitator if sign-in still fails.
